## ✨ Features

- 🎨 **Modern Dark Design**: High-end dark theme built with Chakra UI & Space Grotesk typography.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- ✨ **Smooth Animations**: Interactive elements powered by Framer Motion with typing effects.
- 🎯 **Animated Roles**: Cycles through *Data Science*, *Machine Learning*, *AI Engineering*.
- 🏷️ **Icon-based Expertise Grid**: 4-category 2×2 skill grid — no progress bars, clean chip layout.
- 🗂️ **Two-column Project Layout**: Left = Data Analysis projects · Right = Data Science projects.
- 🔗 **Full Integration**: GitHub repositories, LinkedIn, email and contact form.

## 🏃 Getting Started

1. **Clone the repository**:
```bash
git clone https://github.com/sohamnp06/ML-Portfolio.git
cd MyPortfolio
```

2. **Install dependencies**:
```bash
npm install
```

3. **Start the development server**:
```bash
npm run dev
```

4. **Open [http://localhost:5173](http://localhost:5173)** to view it in the browser.

## 🔧 Customization

Update personal information in the following components:

| Component | Purpose |
|---|---|
| `src/components/Hero.tsx` | Name, animated roles, social links |
| `src/components/About.tsx` | Bio, education, summary |
| `src/components/Expertise.tsx` | Skill categories and tools |
| `src/components/Projects.tsx` | Project cards (Data Analysis + Data Science columns) |
| `src/components/Contact.tsx` | Contact form and details |

Customize theme in `src/App.tsx` via Chakra UI theme configuration.
